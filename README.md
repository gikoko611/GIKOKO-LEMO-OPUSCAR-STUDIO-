# G.I KO KO — Lemo-Opuscar Cloud Studio

A phone-managed video-rendering project. The Redmi 9A is used to control the repository; GitHub-hosted Actions runners perform the rendering in the cloud.

## Current starter features

- 10-second deterministic demo film
- 480p (854×480) and 720p (1280×720) MP4 export options
- H.264/MP4 output generated by the upstream Lemo-Opuscar renderer and FFmpeg
- Rendered MP4 is attached to the workflow run as an artifact for 7 days
- No Android Studio, OpenJDK, or local rendering setup is required on the phone

## Run a cloud render

1. Open the **Actions** tab in this repository.
2. Select **G.I KO KO Cloud Render**.
3. Press **Run workflow**.
4. Choose 480p first for the initial test; choose 720p after it succeeds.
5. Open the completed workflow run and download the `GI-KO-KO-rendered-video` artifact.

## Project layout

- `assets/icons/icon-512.png` — project icon
- `films/demo/index.html` — 10-second test film
- `.github/workflows/cloud-render.yml` — manual cloud-render workflow
- `output/` — generated MP4 output (downloaded as a workflow artifact)

## Important

This is a starter pipeline, not an unlimited free video-rendering service. GitHub usage, artifact storage, runner limits, and upstream dependency availability still apply. The workflow uses a standard GitHub-hosted runner and does not call a paid AI video-generation API.

The workflow clones the upstream renderer at run time: https://github.com/lemomo-ai/lemo-opuscar

The upstream page-rendering contract requires `window.READY`, `window.DUR`, and a deterministic `window.render(t)` function. See the upstream core README for details.
